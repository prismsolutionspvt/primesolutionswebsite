# Admin guide (for the owner)

Open `/admin` on your website and sign in with your email and password. (Forgotten the password? Choose "Email me a sign-in link" and open the link in the same browser.) You can change the password in **Admin Settings**. Everything you change goes live on the website straight away.

## The sidebar

| Page | What you do there |
| --- | --- |
| **Overview** | Live numbers (enquiries, reviews, services, FAQs), what needs attention, latest enquiries, recent changes, quick actions |
| **Company Content** | The home-page opening, company introduction, the closing “Built on trust” statement, contact-section text |
| **Mission & Vision** | The two statements and the phrases that glow while visitors read |
| **Core Values** | Add, edit, hide, reorder values; mark the three guiding principles |
| **Why Prism** | The reasons around the animated ring (any number works) |
| **Our Approach** | The stages of “How we work” |
| **Services** | Services and, inside each, its subcategories; group heading, icon, image, publish/hide, order |
| **Industries** | Industries, which services fit, illustration or image |
| **Team Management** | “Meet the People Behind Prism”: real names, roles, bios, photographs |
| **Testimonials** | **Approve or reject visitor reviews**, feature the best, add your own genuine testimonials |
| **FAQs** | Questions and answers; the topic you type becomes a filter chip |
| **Announcements** | The pop-up: text, button, start/end, priority, how often, can it be closed |
| **Enquiries** | Contact-form messages: search, filter, status, internal notes, copy email/phone, delete |
| **Contact & Social** | Email, phone, address, WhatsApp (country code, number, message, on/off), Instagram, other links, footer small print and scrolling phrases |
| **Admin Settings** | Who can sign in, setup status, change history |

## Everyday tasks

- **Add a service:** Services → *Add service* → fill the Basics/Descriptions → add subcategories at the bottom → *Add service*. Untick *Show on the website* to keep it as a draft.
- **Reorder:** use the up/down arrows on a row; the website follows immediately.
- **Hide instead of delete:** every list has a *Visible/Hidden* switch. Hidden items disappear from the website but are kept.
- **Approve a review:** Testimonials → *Pending* tab → *Approve*. Reviews are never public until you do this. Reject spam; delete anything you do not want to keep.
- **Announcements:** *Enabled* turns it on. “Once per visitor” plus “show again after 7 days” means a visitor sees it, closes it, and is not bothered for a week. If you turn the close button off, it closes itself after 12 seconds. Editing an announcement makes it count as new for everyone.
- **WhatsApp:** enter the country code (digits, no +) and the number (digits). The button, the contact section and the footer all use it. Switch the button off with the toggle.
- **Phone / address:** leave blank and nothing is shown (the site says “Phone number coming soon” where a card would be).

## Things to know

- Text boxes are plain text. Leave a blank line between paragraphs. (No formatting toolbar: it keeps the site safe and consistent.)
- Enquiries are **saved here only**. No email is sent to you, so check **Enquiries** regularly (the sidebar shows a badge for new ones).
- Pictures you can manage: each **team member's photograph**, each **service's image** (shown at the top of the service when opened) and each **industry's image** (replaces the line drawing; leave empty to keep the drawing). Use the **Choose image** button: pick one you uploaded before or upload a new one (JPG, PNG, WebP, AVIF, GIF or ICO, up to 5 MB). Every other optional image field was removed.
- There is no screen for the logo, favicon, share image, theme default or the “Powered by” credit: those keep the values they were set up with (stored in the database).
- If you ever see “Your session has expired”, sign in again.
